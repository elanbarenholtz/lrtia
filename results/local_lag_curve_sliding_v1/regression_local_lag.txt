LOCAL LAG CURVE REGRESSION ANALYSIS (SLIDING WINDOWS)
================================================================================

PRIMARY OUTPUTS: SHAPE METRICS
----------------------------------------
Shape metrics characterize the 'memory-use profile' - how quickly
predictive benefit saturates as context length increases.

  * early_ratio = gain_16 / gain_128 (saturation speed)
  * log_slope_local = slope of gain vs log(k)
  * auc_log_k = AUC on log scale (emphasizes early saturation) [PRIMARY]
  * auc_linear_k = AUC on linear scale (emphasizes longer k)

WHAT WE'RE MEASURING:
----------------------------------------
  - NLL on true next tokens (actual words written)
  - gain_k = NLL(k=0) - NLL(k): how much k tokens of context help
  - Shape of gain_k curve = 'local memory curve'

================================================================================

Configuration:
  Cohort: persuade_score_long (50/50/50)
  Target length T: 32 tokens
  Windows per essay: 20
  Min preceding context: 128 tokens
  End buffer: 64 tokens
  Context grid k: [0, 2, 4, 8, 12, 16, 24, 32, 48, 64, 96, 128]
  Essays analyzed: 150
  Random seed: 42
