Elan is a cognitive scientist / researcher investigating how human memory constraints shape language production, using LLM perplexity and prediction metrics as measurement tools. Works with developmental corpora (ECSC, ENNI, Peterson-McCabe), student essays (PERSUADE), and multi-genre benchmarks (RAID).

Has strong theoretical intuitions — was suspicious of the "too universal" perplexity curves before the controls confirmed the issue. Thinks carefully about what metrics actually measure vs what we want them to measure. Pushes back productively on overinterpretation.

Runs experiments on Google Colab (T4/L4/H100 GPUs). Prefers to iterate quickly through notebook versions rather than build a monolithic pipeline. Comfortable with Colab debugging but benefits from explicit "paste this into a cell" instructions when things go wrong.

Publication target: PNAS-level journals. Frames findings in cognitive science terms (working memory, biological constraints) with computational methods as tools, not as the focus.
